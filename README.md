# German Cultural Research – A1 Interactive Demo 🇩🇪

## Internship Week 1 – Web Demo

This is the coding/demo part of the internship task.

### Features
- German A1 cultural learning topics
- Greetings & etiquette
- Festivals & traditions
- Food & everyday life
- Bauhaus & design
- Interactive lesson cards
- A1 quick quiz
- Responsive design

### Technologies
- HTML5
- CSS3
- JavaScript

### Run Locally

Open `web-demo/index.html` directly in a browser.

Or use VS Code + Live Server.

Optional:
```bash
cd web-demo
python -m http.server 5500
```

Then open:
`http://localhost:5500`

## GitHub Pages

Upload this repository to GitHub and enable GitHub Pages from the repository's Pages settings. The `web-demo` folder can be deployed as the site source.
